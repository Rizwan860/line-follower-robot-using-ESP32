# Contributing

Thanks for taking an interest in this project.

Useful contributions include:
- tested improvements to the steering logic;
- clear wiring or build photographs;
- sensor calibration notes;
- fixes for compatibility with a specific ESP32 Arduino core version;
- measured results from different track widths or sensor spacing.

When suggesting a change, please include the board, motor driver, sensor type, Arduino-ESP32 core version and the readings you observed. Please do not present untested corner logic as proven behavior.
